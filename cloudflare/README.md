## Local release preparation

Run from `cloudflare/` using Node 22.22 or newer. The lock pins Wrangler 4.143.0 and its official dependency graph; both configurations pin compatibility date 2026-10-03.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run verify
npm test
npm run check:local
```

The build fails before emitting a new artifact if the reviewed public allowlist, any source hash, MIME/header contract, Vercel configuration or exact analytics-removal guard changes. It never runs the in-place version/build-info writers. Repeated builds are deterministic. `npm run verify` checks the generated bytes, source hashes, Worker, derived policy, lock and both configuration inputs; run it immediately before any root-owned deployment.

`npm run check:local` starts and stops only local workerd on ports 8896/8897. It checks all 350 preview outputs, exact headers, HTTPS canonical production hosts, framing exceptions, AASA, studio privacy, cache/query behavior, safe redirects, complete 404 bodies despite validators/ranges, media ranges, conditional/HEAD requests, origin denial and forbidden methods. HTTPS uses a local certificate only; this is not hosted or device proof. `verification/` and `output/` are ignored review artifacts.

## Hosting policy and isolation

`hosting-policy.mjs` derives clean routes and effective headers from public filenames and explicit exceptions. Its policy is checked against every original observed production header profile. There is no SPA fallback or broad asset catchall. The Worker invokes only `ASSETS.fetch`; it does not proxy any app backend. `/embed` and `/tour` remain frameable; `/studio` remains private/no-store/noindex; AASA retains JSON MIME and one-hour caching. A binding failure returns a generic no-store/noindex 503 body and exposes no provider failure text.

Only `CF_DEPLOYMENT_ENV=production` on `https://veylet.com` or `https://www.veylet.com` is treated as production. Missing/unknown modes remain preview. Preview access uses an exact origin allowlist: the existing `veylet-site-preview.yda31416.workers.dev` host and local port8896. Unexpected origins return 403/no-store/noindex. Preview CSP blocks external scripts, connections and forms, while permitting same-origin static media and blob workers. Every preview response is noindex; preview robots disallows all crawling. Production keeps the original public integration policy and original robots body.

`wrangler.production.jsonc` now maintains the two HTTPS-only routes already activated by root: `https://veylet.com/*` and `https://www.veylet.com/*`, both in zone `veylet.com`. Account `195cf1d6da99ca2d1e64e0069e0d87c6`, Worker `veylet-site` and production marker remain pinned. The verifier rejects route removal, a scheme-less/HTTP/wildcard route, custom-domain routing, tenant/name drift or unexpected app bindings. These are Worker Routes over the existing proxied Vercel CNAME records; no DNS mutation is encoded. HTTP stays outside the Worker because explicit HTTPS schemes match only HTTPS; free Cloudflare redirect rule `2391bd861f48448f8c025a35debbff55` now performs the HTTP 308 upgrade while preserving hostname/path/query. HTTP no longer depends on the retained Vercel origin. See [the current redirect receipt](HTTP-REDIRECT-UPDATE-2026-10-11.md). See the [official route rules](https://developers.cloudflare.com/workers/configuration/routing/routes/) and [Wrangler route configuration](https://developers.cloudflare.com/workers/wrangler/configuration/#routes).
